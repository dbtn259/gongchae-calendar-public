# 공채 데이터 자동 업데이트 절차

예약 작업이 매주 이 절차를 그대로 수행합니다. 사람이 손으로 할 때도 같은 순서를 따르세요.

## 대상
- 로봇기업: 두산로보틱스, HD현대로보틱스, 레인보우로보틱스, 한화로보틱스, 현대차·현대모비스 로보틱스 부문 등
- 대기업: 삼성, SK하이닉스, LG, 현대자동차·현대모비스·현대위아·현대로템, HD현대, 한화(에어로스페이스·오션), 두산, 포스코, LIG넥스원, KAI, 롯데, CJ, 아모레퍼시픽, DB하이텍 등
- 신입 공채 우선, 경력 공채는 `exp: true`

## 순서
1. `data/recruits.js` 를 읽어 이미 있는 공고를 파악한다.
2. 웹에서 새 공고와 변경된 일정을 찾는다 (링커리어 activity 페이지, 기업 채용 홈페이지, 대학 취업게시판, 언론 보도).
   - **공고 원문이나 공식 채용 페이지에서 날짜를 확인한 것만** 넣는다. "예상" 일정은 넣지 않는다.
   - 시작일을 확인할 수 없으면 `start: null`.
3. 새 항목 추가 / 바뀐 날짜 수정. 기존 `id` 는 절대 바꾸지 않는다.
   - `id` 형식: `기업영문-연도+시기` (예: `samsung-2027h1`, `lg-2026-06`)
   - `mech`: 설계·R&D·생산기술·품질·설비 직무 모집이면 `true`
   - `url`: 해당 공고로 바로 가는 링크, `source`: 날짜를 확인한 페이지
4. `RECRUIT_META.updated` 를 오늘 날짜로 바꾼다.
5. `node scripts/validate-data.mjs` 를 실행해 통과하는지 확인한다.
6. 변경이 있으면 커밋: `공채 데이터 업데이트 YYYY-MM-DD (+추가 n건, 수정 m건)`
7. 바뀐 내용(추가·수정된 공고와 마감일)을 짧게 보고한다. 변경이 없으면 "변경 없음"만 보고한다.
